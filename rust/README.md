
# Unarian - Rust Interpreter

This Rust interpreter is intended to be a fully-featured version of the [minimal Rust interpreter](../rust_min/README.md) with more command-line functionality, improved error detection and messages, significantly increased execution speed, a bytecode compiler and interpreter, and an interactive execution environment (a REPL). How successfully it achieves this goal is unclear.
